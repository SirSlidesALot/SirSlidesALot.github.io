# SirSlidesALot Realmaps

The landing page for the Realmaps project: a globe with every map at its real
location and its true footprint. Zoomed in, each footprint becomes a plate: the
map itself seen from straight above (its own terrain colour, shaded by its own
heightmap, its water drawn as water), sharp where the globe's own imagery is
~10 km a pixel. Clicking a map flies into its plate and opens its sheet with
facts and screenshots. Served by GitHub Pages at <https://sirslidesalot.github.io>.

A static site with no build step: `index.html`, `assets/`, `data/maps.json` and
`maps/<id>/*.jpg`.

## Updating it

Nothing here is edited by hand except the page itself (`index.html`, `assets/`,
`CREDITS.md`). `data/maps.json` and `maps/<id>/*.jpg` (stills, and `plate.jpg` /
`plate_lo.jpg`) are GENERATED by the
realmaps repository from its `showcase/<map>/` sources and each map's build:

```
scripts/showcase.py site --out <this repo>
```

That step refuses to run when any map lacks a showcase entry, a status, a pitch
or a still, so a new map cannot be left off the globe.

Preview locally with `.venv/Scripts/python.exe -m http.server 8765` and open
<http://127.0.0.1:8765>. A deep link to one map is `#<id>`, e.g. `#thasos_island`.

Credits for the data behind the screenshots are in [CREDITS.md](CREDITS.md).
